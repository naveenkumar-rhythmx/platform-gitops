# Directory Tree

Annotated map of every top-level area of `platform-gitops`. Generated by
hand alongside the initial platform build-out; re-generate/update the
comments (not just re-run `find`) whenever a directory's *purpose* changes,
since the value here is the annotation, not the raw listing.

To regenerate the raw listing at any time:

```bash
find . -type f -not -path './.git/*' | sort
```

## Sibling repositories (not in this tree)

- `platform-helm-charts` — versioned OCI chart packaging consumed by `clusters/*/{infrastructure,platform}/kustomization.yaml` and by `applications/*` reference Applications.
- `application-config` — per-service, per-environment overlays (image tags, replica counts) consumed by `app-of-apps/applicationset-workloads.yaml`.

See [`docs/architecture/repository-strategy.md`](architecture/repository-strategy.md) for the full rationale.
